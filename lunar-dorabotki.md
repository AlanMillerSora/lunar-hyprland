# Задание для домашней ИИ — доработки Lunar Eclipse

> Этот файл передаётся ИИ-агенту на машине с Arch + Hyprland.
> Ты — агент, который дорабатывает репозиторий `lunar-hyprland`
> (AlanMillerSora/lunar-hyprland). Читай и выполняй по порядку,
> отмечай пункты `[x]` по мере готовности.

---

## 0. Контекст (прочитать перед работой)

- Проект: **Lunar Eclipse** — Hyprland rice. Весь шелл (панель, Hub-лаунчер,
  sidebar'ы, OSD, меню питания) написан на **Quickshell (QML)**.
  `waybar` и GTK-приложения не используются.
- Репозиторий живёт в `~/rice` (клон `https://github.com/AlanMillerSora/lunar-hyprland`).
- **Правь ТОЛЬКО репозиторий** (`~/rice`), а не живые `~/.config`:
  `./install.sh` перезаписывает конфиги в `~/.config` из репо.
- Обязательно прочитай `~/rice/AGENTS.md` — там правила работы агента
  и закрытые темы (их не поднимать).
- Требуется Hyprland 0.55+ (конфиг — `hyprland.lua`, не `.conf`).
- `./get-deps.sh` — зависимости (Arch), `./install.sh` — установка конфигов.
- Проверка синтаксиса конфига: `hyprctl configerrors`.
- **После поведенческих изменений — бамп `VERSION`** (файл в корне репо).

## 1. Правила выполнения

- Работай по задачам ниже, в порядке приоритета (сначала 01).
- После каждой задачи проверяй результат (см. «Как проверить»),
  только потом переходи к следующей.
- Если задача требует правок в живом `~/.config` для проверки —
  сначала коммить в репо, потом применяй `./install.sh`.
- `pkill` по PID, не по имени (`hyprctl clients -j`, `pgrep`).
- Не читай 30+ картинок за сессию — проверяй по логам и `hyprctl`.

## Задача 01 — Авто-рестарт Quickshell (панель не должна «умирать») ✅ ВЫПОЛНЕНО

**Зачем:** сейчас панель/лаунчер/OSD живут в одном процессе `quickshell`,
который запускается один раз в `hyprland.lua` (`hl.on("hyprland.start", …)`).
Если процесс упадёт — панель исчезает до перелогина.

**Статус: ВЫПОЛНЕНО (коммит `288c4f9`, VERSION 1.25.0).**

**Что сделать:**
- [x] Создать systemd-user-юнит `systemd/lunar-quickshell.service`
      (~/.config/systemd/user/ после `install.sh`):
  - `ExecStart=/usr/bin/quickshell`
  - `Restart=always`, `RestartSec=2`
  - `Nice=-5`
  - `Type=simple`
  - НЕ включать юнит в автозапуск (enable) — он стартует из hyprland.lua
    (иначе запустится раньше композитора и будет падать без Wayland).
- [x] Изменить автозапуск в `.config/hypr/hyprland.lua`:
  - вместо `hl.exec_cmd("quickshell")` —
    сначала `systemctl --user import-environment DISPLAY WAYLAND_DISPLAY
    XDG_CURRENT_DESKTOP XDG_SESSION_TYPE` (чтобы юнит увидел env сессии),
    затем `systemctl --user --no-block start lunar-quickshell.service`
    (`--no-block`, чтобы не тормозить автозапуск).
- [x] Проверить, что `install.sh` копирует новый юнит (блок копирует
      `$REPO/systemd/*.service` — автоматически) и перезагружает юниты
      (`systemctl --user daemon-reload`). Плюс явный `disable`, чтобы юнит
      не ушёл в автозагрузку раньше Wayland.
- [x] Бамп `VERSION` → 1.25.0.

**Как проверить:**
- [x] `pgrep -x quickshell` после старта сессии — процесс есть.
- [x] `systemctl --user status lunar-quickshell.service` — active (running),
      в логе нет падений на старте.
- [x] `pkill -x quickshell` → через ~2–4 секунды `pgrep -x quickshell`
      снова показывает процесс, панель на месте (без перелогина).
- [x] `hyprctl configerrors` — чисто.

## Задача 04 — Запись экрана через NVENC (GPU-кодирование) ✅ ВЫПОЛНЕНО

`libva-nvidia-driver` (NVENC), проверить на ПК.

**Зачем:** сейчас `wf-recorder` кодирует софтом — на 3440×1440 при игре
запись просаживает FPS. На NVIDIA (RTX 5070) есть аппаратный энкодер
(NVENC через VAAPI; `libva-nvidia-driver` уже ставится в `get-deps.sh`).

**Что сделать:**
- [x] В `get-deps.sh` добавить `libva-utils` (утилита `vainfo` —
      диагностика аппаратных кодеков). `libva-nvidia-driver` уже есть.
- [x] **NVIDIA-блок — только при наличии GPU NVIDIA** (проверка
      `lspci`/`/sys/class/drm`): `libva-nvidia-driver`, `libva-utils` и всё
      NVIDIA-связанное устанавливать ТОЛЬКО если карта NVIDIA есть.
      На ноуте (без NVIDIA) ничего NVIDIA не ставится и не настраивается —
      `get-deps.sh` пропускает этот блок полностью. (В else-ветке для AMD/Intel

  - вывод в статус/notify: «NVENC (VAAPI)» / «GPU (VAAPI)» / «софт (libx264)».

**Как проверить:**

## Черновики решений (мысли при обсуждении — учитывать, но проверять)

- **Откат системы** — ВЛИТ в Задачу 07 (кнопка «Откат» во вкладке
  «Обновление» в Hub). Диск ext4 → **timeshift** (rsync-снимки),
  snapper/grub-btrfs НЕ брать. Git-откат покрывает только конфиги риса,
  системные поломки — только timeshift.

- **Права sudo для агента в чате (Задача 08)** — РЕШЕНО: белый список
  доверенных команд в `visudo` (`pacman/yay`, `systemctl`, `hyprctl`,
  `journalctl`, скрипты `~/rice`), остальное — подтверждение в чате.

- **CI / GitHub Actions** — пользователь предложит свой вариант позже.
  Пока НИЧЕГО не делать, задачу не ставить.

- **Обои (Задача 12)** — РЕШЕНО: живой рендер сцены нативным QML
  в Quickshell (`LunarWallpaper.qml`, слой Background), без видео/webm/
  mpvpaper и без браузерного движка. Chromium/WebKit отклонены — тяжело
  и «не хавают»; mpv+webm — мёртвая картинка. Сайт `sait/` остаётся
  спекой. QML на Windows не запустить (нужен Wayland/Hyprland), поэтому
  сцена пишется чистым QtQuick + `preview.qml` для проверки рис
  любым Qt6-раннером. Полноэкранного блюра в сцене нет (только 2 мелких
  локальных), «лёгкий режим» — запасной тумблер в Hub.

- **Скриншоты не менять**: `PRINT` = область в буфер (аналог ножниц) —
  пользователя устраивает. swappy/редактор не добавлять.
- **Мониторные хоткеи НЕ нужны** (`SUPER+,/.` и `SUPER+SHIFT+,/.`): на ПК один
  ультраширокий 3440×1440, ноут — один экран. Не добавлять.
- Quickshell под systemd с `Restart=always` — самый надёжный путь;
  важно передавать env сессии через `import-environment` (иначе юнит
  не увидит `WAYLAND_DISPLAY`).
- `Restart=always` держит шелл живым независимо от того, кто его запустил;
  при `hyprctl reload` повторный `systemctl --user start` — no-op, шелл не сбрасывается.
- Для релиза: локально хватает `release.sh` + тег; Workflow сам делает Release
  (без `gh` и токенов у пользователя).
- `install.sh` уже копирует все `systemd/*.service` — новые юниты попадают
  сами, важно только не включать quickshell в enable.
- Из сравнения с Windows (не в репо): система сильна в разработке/флоу/ресурсах;
  Windows — в играх с античитами, проприетарном софте и простоте для не-технарей.
