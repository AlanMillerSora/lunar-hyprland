# Обновления

## update 0.1.3 — 18.09.2026

Полировка системы: рабочий waybar, оверлей хоткеев, нарядный терминал с
fastfetch, аккуратные wofi и Dolphin. Всё — в палитре райса, без лишних
зависимостей.

### Waybar

- **Индикатор затмения переделан**: тонкая полоса заполнения из 10 делений
  (`━` / `─`) + лунный глиф текущей фазы + процент. На полном затмении
  (фаза 4) — красный (`#f2657a`) с мягким свечением, в остальных фазах —
  акцентный `#7ea6ff`.
- **Громкость** — клик открывает `pavucontrol` (полное управление), правый
  клик — mute, колесо — громкость ±5%.
- **Wi-Fi** — клик открывает меню сетей (`eclipse-network.sh`), правый клик —
  `nm-connection-editor`.
- **Календарь** — клик по часам открывает кастомный GTK-календарь
  (`eclipse-calendar.py`): навигация стрелками/PgUp-PgDn, клик по дню
  копирует дату в буфер.
- Убран дублирующий модуль даты, добавлены `hover`-подсветки и красивый tooltip.
- Медиа-клавиши (`XF86Audio*`) через `wpctl`.

### Горячие клавиши

- `SUPER` + `/` открывает оверлей со списком горячих клавиш
  (`eclipse-cheatsheet.py`), сгруппированный по разделам, с клавишами-«кэпами».
- `SUPER` + `E` открывает Dolphin.
- Попапы календаря/шпаргалки/ввода пароля — плавающие, по центру, без рамок
  (оконные правила в `hyprland.lua`).

### Терминал

- **kitty**: аккуратный курсор-beam с трейлом, паддинги 10, вкладки появляются
  только при ≥2 вкладках, `confirm_os_window_close 0`, `copy_on_select`.
- **fastfetch** с логотипом-полузатмением: `fastfetch/eclipse.svg` рендерится
  в `eclipse.png` (kitty-графика), конфиг `fastfetch/config.jsonc`.
- **`shell/lunar.bash`**: приветствие fastfetch при старте kitty, алиасы,
  цветной PS1 с луной; подключается из `~/.bashrc` установщиком.

### Лаунчер и файловый менеджер

- **wofi**: центрированное окно, скругления 18px, тень, аккуратный ввод,
  подсветка выбранного, тонкий скроллбар.
- **Dolphin/KDE**: цветовая схема `Lunar Eclipse` (`~/.local/share/color-schemes`),
  `kdeglobals` (тёмная тема, шрифты Inter, иконки breeze-dark, `Breeze`),
  `dolphinrc` (компактный список, скрытая строка меню/статуса).

### Установка

- `install.sh` копирует новые скрипты, конфиг fastfetch, тему KDE и
  подключает `lunar.bash` к `~/.bashrc`.
- `setup.sh` ставит `fastfetch` из extra.

## update 0.1.2 — 18.09.2026

Живые обои **один-в-один с веб-превью** `sait/`. Возврат к видео-режиму:
на каждом столе крутится своя фаза затмения, полный цвет, 60 fps, без
256-цветного зерна и полос.

### Живые обои

- **`hypr/scripts/eclipse-live-gen.py`** — новый генератор: снимает кадры
  прямо с живой CSS-сцены сайта (`sait/index.html?phase=N&clean=1`) через
  headless Chromium (CDP) и кодирует в VP9 10-бит (`yuv420p10le`, CRF 18).
  Вид 1-в-1 с превью: радиус солнца 125, на 4-м столе — чёрная луна с тонким
  кольцом. 12-секундная бесшовная петля, 60 fps, 1920×1080, 720 кадров/фаза.
- **`hypr/scripts/eclipse-anim-gen.py`** — новый генератор из SVG-порта
  `exportPhaseSVG()` (та же сцена, что отдаёт кнопка «Скачать обои»): мерцание
  звёзд, дыхание гало, дрейф пыли, пульс короны, метеоры → animated GIF для
  `awww` и/или видео для `mpvpaper`.
- **`eclipse-walls.sh` выбирает режим сам**: есть `mpvpaper` + `eclipse_NN.webm`
  → один mpv-процесс на все мониторы, фаза переключается через IPC (`loadfile`)
  по сокету `$XDG_RUNTIME_DIR/eclipse-mpvpaper-<uid>.sock` — без вспышек и
  перезапусков; иначе `awww` + GIF (fallback PNG/JPG), переход `fade` 0.6 с.
- **Бесшовная петля**: длительности CSS-анимаций квантуются на делители длины
  петли, таймеры гасятся, `Math.random` засеян (`capture.html` собирается из
  `index.html`, сам сайт не трогается). Иначе шов петли «прыгает».
- **Видео-режим**: `yay -S mpvpaper`, затем перезапустить `eclipse-walls.sh`.
  `install.sh` умеет `ECLIPSE_VIDEO=1` (видео) и `ECLIPSE_LIVE=1` (вид 1-в-1
  с сайтом, нужен `chromium`).

### Прочее

- `README.md`: разделы «Живые обои» и «Про качество», команды генераторов.
- `HANDOFF.md`: заметки по live-gen, граблям CDP и планировщику.
- `install.sh`: копирует оба генератора, генерирует живые обои на выбор.
- `setup.sh`: в пакеты добавлены `librsvg` и `ffmpeg`, подсказка про видео.
- `.gitignore`: `__pycache__/`, `*.pyc`.

### Исправления

- `eclipse-live-gen.py`: фазы рендерятся **параллельно** — раньше цикл по фазам
  шёл последовательно (~48 минут на 8 фаз), теперь ~2–3 минуты на фазу, и те
  идут одновременно.
- `eclipse-live-gen.py`: Chromium запускается в своей группе процессов
  (`os.setsid`) и убивается по группе — больше не остаётся осиротевших
  браузеров, которые жрали память и путались под ногами.
