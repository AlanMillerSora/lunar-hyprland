# AGENTS.md — Lunar Eclipse

## Правила работы агента

- **Не читай больше ~30 изображений за одну сессию.** У модели есть жёсткий лимит на картинки:
  при превышении провайдер отдаёт ошибку и сессия обрывается — агент «зависает». Проверяй результат
  по логам, `grep`, `hyprctl`, а скриншоты/превью читай только по необходимости (одно-два на проверку).
- Правь исходники в репозитории, а не живые `~/.config`: `./install.sh` их перезаписывает.
- Перед удалением или перезаписью незнакомых файлов — сначала посмотри, что это (возможно, работа пользователя).
- Не чейни команды через `echo "====";` / `printf '---'` — вывод становится шумным. Отдельные вызовы.
- Не убивай процессы по имени: `pkill -f "<текст>"` может убить собственный шелл, а `pkill -x <имя>` бьёт
  по всем экземплярам (например, все `kitty` пользователя). Убивай по PID (`hyprctl clients -j`, `pgrep`).
- **Коммиты — от лица автора риса.** Первым лицом, по-русски, что и зачем сделал:
  «убрал серп», «починил трафик-трекер». Никаких «пользователь попросил», «по правке
  пользователя», «запрошено» — история должна выглядеть так, будто её ведёт сам автор.

## Правила репозитория

- **Hyprland настроен на Lua**: `hyprland.lua`, а не `hyprland.conf`. Требуется Hyprland 0.55+.
- **Правь только репозиторий.** `./install.sh` копирует `.config/*` в `~/.config` и **перезаписывает**
  установленные конфиги — изменения, сделанные в `~/.config` напрямую, будут потеряны.
- После изменений, меняющих поведение, бампай `VERSION`.
- Релиз делается `./release.sh`: тег `v<VERSION>` уходит в origin, а GitHub Actions
  (`.github/workflows/release.yml`) сам создаёт Release с заметками из коммитов.
  Рабочее дерево перед релизом должно быть чистым.
- Зависимости перечислены в `./get-deps.sh`.
- Конфиг Hyprland 0.55+ использует Lua-синтаксис (`hl.animation`, `hl.windowrule`), не старый
  строчный формат.
- **GPU-зависимые настройки — только условно.** Рис работает и на NVIDIA, и на AMD/Intel:
  переменные окружения NVIDIA (`hyprland.lua`) включаются по определению карты через
  `/sys/class/drm/*/device/vendor` (`0x10de` — NVIDIA), чтобы не сломать рендер на других GPU.
  Драйвер NVIDIA в Arch 615 — `nvidia-open-dkms` (проприетарного `nvidia-dkms` больше нет).

## Соглашения проекта

- Визуальный язык: фон `#050505`, текст `#ffffff`, приглушённый `#888888`, опасность `#ff003c`,
  рамка 1px, радиус 6, шрифт JetBrains Mono.
- Shell написан на Quickshell (QML); waybar и GTK-приложения не используются.
- Комментарии и вывод скриптов — на русском.

## Что не предлагать

Темы закрыты навсегда — не поднимать повторно:

- **«Экономный» пресет** под слабое железо — не предлагать.
- **Статичные обои вместо видео** (awww вместо mpvpaper) — не предлагать.
